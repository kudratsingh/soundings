## Title

Soundings: from seen to handled, at the gentlest rung

## Description

An unknown vehicle is underwater in a working harbor. Today the safe answer is to close the berth. Soundings climbs a ladder instead: watch, ask, slow, hold, hand to a person. It asks first, with a registry check and an acoustic hail, holds one berth only under orders the watch commander signed in advance, and hands a person a report where every line points at its evidence. The work stops at the handoff; the call is a person's.

The same tool runs the ordinary day: a registry for planned underwater work, filed from a phone, and a search for the research vehicle that went quiet. Detection in this demo is a stated, simple physics model; the decisions are deterministic code with tests. Built in 48 hours at the InnovateLA Dual-Use Hackathon (USC, Track 01 Marine, with NULL Labs). Code: https://github.com/kudratsingh/soundings
